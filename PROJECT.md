# Project: Reconcilyx

Status: `v4.0.0-beta` in active hardening. Not production-ready.

This repository contains the Kubernetes operator, the control-plane API, the `kubectl-reconcilyx` plugin, and the embedded React console.

Start with:

- [README.md](README.md) — supported deployment models and development workflow
- [STATUS.md](STATUS.md) — release posture and remediation evidence
- [FEATURE_MATRIX.md](FEATURE_MATRIX.md) — conservative feature inventory
- [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) — VPS, Helm, and local evaluation instructions

No public hosted dashboard is operated. The console ships inside the Hub binary.
